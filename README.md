# viewstats-privacy

Official privacy policy for ViewStats for YouTube & Twitch.

Published at <https://playspansupport.github.io/viewstats-privacy/>.

The policy in `index.md` must stay in step with `PRIVACY.md` inside the
extension package and with the data-usage answers in the Chrome Web Store
dashboard. A reviewer can read all three, and any disagreement between them is
worse than any one of them being brief.
