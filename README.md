# viewstats-privacy

Official privacy policy for **Spool for YouTube & Twitch**.

Published at https://playspansupport.github.io/viewstats-privacy/

> The repository keeps its original name on purpose. GitHub Pages does not
> reliably redirect a project page after a rename, and this URL is referenced
> by the extension's manifest and by the live Chrome Web Store listing.
> Renaming the repository would break the privacy policy link in a shipped
> product. Spool was previously called ViewStats; only the path is left over.

The policy in `index.md` must stay in step with `PRIVACY.md` inside the
extension package and with the data-usage answers in the Chrome Web Store
dashboard. A reviewer can read all three, and any disagreement between them is
worse than any one of them being brief.
